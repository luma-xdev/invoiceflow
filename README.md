# InvoiceFlow

> A professional freelance invoice generator built as a real-world business tool.

## 🌐 Live Demo

https://luma-xdev.github.io/invoiceflowbyluma/

## ✨ Features

- Professional invoice generation
- Freelancer and business details
- Client information
- Dynamic invoice items
- Add and remove services
- Automatic subtotal calculation
- Tax calculation
- Discount calculation
- Automatic grand total
- Multiple currencies
- Invoice number generation
- Invoice date and due date
- Live invoice preview
- Auto-save with browser local storage
- Print-ready invoice
- Responsive mobile design
- Dark and light interface
- No database required

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- Browser Local Storage
